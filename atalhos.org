#+TITLE: Atalhos

* Globais
+ ~<f1>~  abrir scratch buffer
+ ~<f5>~  trocar tema por listagem
+ ~<f6>~  trocar/percorrer temas
+ ~C-_~   diminuir tamanho da fonte
+ ~C-+~   aumentar tamanho da fonte

* Janelas
+ ~C-tab~ alternar janela
+ ~C-k~   fechar buffer e janela
+ ~C-b~   trocar de buffer
+ ~C-,~   abrir/fechar popup
+ ~C-<~   ciclar popups

* Edição de texto (sem prefixos)
+ ~C-p~ colar
+ ~M-w~ copiar seleção
+ ~C-w~ recortar seleção
+ ~M-y~ histórico de cópias
+ ~C-=~ expandir seleção (selecionar palavra, depois frase, etc) ~repetível~
+ ~M-k~ apagar do cursor até fim da linha
+ ~C-o~ criar nova linha abaixo
+ ~M ↓~ mover linha para baixo
+ ~M ↑~ mover linha para cima
+ ~M-u~ converter palavra/seleção para MAIÚSCULAS ~repetível~
+ ~M-l~ converter palavra/seleção para minúsculas ~repetível~
+ ~M-c~ converter palavra/seleção para Capitalizada ~repetível~
+ ~M-t~ inverter palavra com a próxima
+ ~M-p~ duplicar linha ~repetível~

* Movimentos
+ ~M-j~ digitar início de palavra e pular para o local
+ ~M ←~ ir para o início da linha
+ ~M →~ ir para o fim da linha
+ ~M-a~ início da sentença
+ ~M-e~ fim da sentença
+ ~M-<~ início do arquivo
+ ~M->~ fim do arquivo

* ~M-d~ · Dired (comandos abaixo funcionam após entrar no Dired)
+ ~q~    fechar dired
+ ~RET~  entrar em pasta
+ ~M-←~  voltar para pasta anterior
+ ~M-d~  criar nova pasta
+ ~M-f~  criar novo arquivo
+ ~M-.~  exibir/ocultar arquivos ocultos
+ ~<f2>~ editar nomes de arquivos/pastas
+ ~D~    deletar arquivo
+ ~C~    copiar arquivo
+ ~R~    mover arquivo passando o caminho da pasta
+ ~m~    marcar arquivos para executar ações (deletar, mover, etc) em todos
+ ~u~    desmarcar um arquivo marcado
+ ~U~    desmarcar todos os arquivos marcados

* C-d · Deletar :repetível:
+ ~C-d d~ deletar linha
+ ~C-d w~ deletar símbolo
+ ~C-d p~ deletar parágrafo
+ ~C-d (~ deletar conteúdo dentro de ~()~
+ ~C-d [~ deletar conteúdo dentro de ~[]~
+ ~C-d {~ deletar conteúdo dentro de ~{}~

* C-y · Copiar
+ ~C-y y~ copiar linha (com região selecionada, copia a região)
+ ~C-y w~ copiar símbolo
+ ~C-y p~ copiar parágrafo
+ ~C-y (~ copiar conteúdo dentro de ~()~
+ ~C-y [~ copiar conteúdo dentro de ~[]~
+ ~C-y {~ copiar conteúdo dentro de ~{}~

* C-s · Buscar
+ ~C-s s~ buscar linha no buffer atual
+ ~C-s t~ buscar por seção/título
+ ~C-s g~ buscar com ripgrep
+ ~C-s r~ arquivos recentes
+ ~C-s b~ bookmarks

* C-r · Substituir
+ ~C-r r~ substituir string
+ ~C-r q~ substituir com confirmação

* C-f · Arquivo
+ ~C-f f~ buscar e abrir arquivo
+ ~C-f d~ buscar arquivo recursivamente
+ ~C-f s~ salvar arquivo atual
+ ~C-f r~ renomear arquivo atual

* C-e · Emacs
+ ~C-e i~ abrir init.el
+ ~C-e e~ abrir atalhos
+ ~C-e r~ reiniciar Emacs
+ ~C-e t~ alternar quebra de linha visual

* C-. · Múltiplos cursores :repetível:
+ ~C-. .~ adicionar cursor na linha de baixo
+ ~C-. /~ adicionar cursor na linha de cima
+ ~C-. m~ adicionar cursor em todas as ocorrências de uma palavra na região selecionada

* C-t · Ferramentas
+ ~C-t t~ abrir terminal
+ ~C-t d~ consultar devdocs
+ ~C-t b~ abrir menu de buffers
+ ~C-t m~ abrir magit

* C-l · LSP/ruby
+ ~C-l d~ pular para diagnóstico
+ ~C-l n~ renomear símbolo
+ ~C-l b~ enviar buffer para REPL (ruby)
+ ~C-l s~ enviar região para REPL (ruby)
+ ~C-l l~ enviar linha para REPL (ruby)
+ ~C-l r~ abrir REPL inf-ruby (ruby)

* C-; · Comentar :repetível:
+ ~C-; ;~ comentar/descomentar linha
+ ~C-; p~ comentar/descomentar parágrafo

* C-q · Marcação de texto
+ ~C-q q~ marcar região selecionada ou palavra sob o cursor
+ ~C-q o~ abrir anotações (após anotar, salvar normalmente)
+ ~C-q d~ remover destaque sob o cursor
+ ~C-q c~ alterar marcação (trocar para sublinhado, etc)
